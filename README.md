# Guessing Game in C

This is a simple number guessing game written in C.

## Features

- Random number generation
- Difficulty levels (easy, medium, hard)
- Limited number of attempts
- Replay option

## How it works

The program generates a number based on the selected difficulty.
The player tries to guess the number, receiving hints ("higher" or "lower") after each attempt.

## How to run

```bash
gcc guessing_game.c -o game
./game
